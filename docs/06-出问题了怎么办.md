# 出问题了怎么办

> 先做 30 秒自检，再按症状查。**每一步只回答一个问题，别跳步。**

---

## 30 秒自检

照着敲，看结果：

**① 服务端在跑吗？**（在服务器窗口里）

```bash
sudo ss -ltnp | grep 443
```

有 `xray` 字样 → 在跑；什么都没有 → 看第 1 条。

**② 你的电脑能连上吗？**（在本机 PowerShell 里）

```powershell
Test-NetConnection 你的IP -Port 443
```

最后一行 `TcpTestSucceeded : True` → 通；`False` → 看第 1 条。

**③ 本地程序在跑吗？**

```powershell
netstat -ano | findstr 10809
```

有输出 → 在跑；空的 → 看第 7 条。

## 按症状查

### 症状：浏览器打不开任何网页，所有网站都不行

**可能是**：代理设了，但本地程序没在跑（等于把网络指向了一个不存在的门）。

**怎么办**：

1. 找那个黑窗口（`xray.exe run -c config.json`），是不是被关了
2. 关了就在文件夹里重新打开，敲 `xray.exe run -c config.json`
3. 还是不行，先把代理关掉，恢复正常上网：
   - 设置 → 网络和 Internet → 代理 → 关掉「使用代理服务器」

**做完**：至少国内网站能打开，再继续查代理的问题。

---

### 症状：GitHub 能开，但 Google / ChatGPT 打不开

**可能是**：本地程序在跑，但服务端认证没过（参数填错）。

**怎么办**：

1. 检查 `config.json` 里四处：IP、UUID、publicKey、shortId
2. **逐字符对比**（最容易错的地方）：
   - UUID 是 `8-4-4-4-12` 的格式，别少横线
   - publicKey 是 **43 个字符**，大小写敏感
   - shortId 是 **16 个字符**，全小写十六进制
3. 一个字符都不能差。实在看不出来，把两个文件都发给 AI 让它比对

---

### 症状：命令行能通，浏览器打不开

**可能是**：命令行和浏览器用的是两套设置。

- 浏览器读的是 **系统代理**（设置里那个开关）
- 命令行（curl/git/pip）读的是 **环境变量**

**怎么办**：先完全退出浏览器（所有窗口），再打开。浏览器只在**启动时**读一次代理设置，
刷新没用。

---

### 症状：昨天还好好的，今天连不上了

**可能是**：服务器 IP 被重点盯上了（俗称"IP 被墙"）。

**怎么办**：

1. 先确认服务端还活着：登录服务器，`sudo systemctl status xray` 显示 active
2. 再确认端口：`sudo ss -ltnp | grep 443` 有 xray
3. 都正常但就是连不上 → IP 被封了
4. **处理**：去 AWS 控制台给实例换一个公网 IP（或重建实例），几分钟的事
   - 换完记得改客户端 `config.json` 里的 IP

> 这就是自建最大的好处：你能换。机场你只能等。

---

### 症状：安装脚本跑完没打印参数框

**可能是**：脚本中途失败了。

**怎么办**：

```bash
# 看配置有没有写进去
sudo stat -c '%s bytes' /usr/local/etc/xray/config.json
```

- 显示 `3 bytes` → 配置是空的，脚本没写完。手动重跑一次脚本
- 显示几百到几千 bytes → 配置在，但服务没起来，看日志：

```bash
sudo journalctl -u xray -n 30 --no-pager
```

把这段输出复制给 AI，让它判断。

---

### 症状：`REALITY authentication failed` / `认证失败`

**可能是**：客户端和服务端的版本对不上，或者密钥不是一对。

**怎么办**：

1. 确保客户端是 **Xray 官方**（我们文档里那个），不是机场客户端自带的内核
2. 很多 Clash/mihomo 系客户端**连不上新版 Xray**，报错就是这个
3. 如果你用的是 Shadowrocket / v2rayNG / Karing，一般没问题

> 详细原理见 [进阶/05-排障手册.md](进阶/05-排障手册.md) 第 3 条。

---

### 症状：本地程序一闪就消失，或者报红字

**可能是**：`config.json` 格式错了（少了逗号、多了中文、引号不配对）。

**怎么办**：

1. 把这个文件内容整个复制给 AI，说"帮我检查 JSON 格式哪里错了"
2. 或者重新从 [04a-Windows](04a-第三步-让电脑用上它-Windows.md) / [04b-macOS](04b-第三步-让电脑用上它-macOS.md) 复制一份完整的，只改那四处
3. 最常见的原因：**某个"改成你的XX"没替换干净**

---

### 症状：B 站 / 抖音变慢，或者提示"网络异常"

**可能是**：模式选成了「全局」，所有流量都绕国外了。

**怎么办**：

- 电脑：检查 `config.json` 里 `routing` 那三行规则还在不在
- 手机：设置里把模式改成「规则 / 绕过大陆」

---

### 症状：网页能开，但视频很卡

**可能是**：这条线路本身的带宽，或者你本地 WiFi 信号差。

**怎么办**：

1. 先测本地网速（不开代理时）——如果本地就只有 20 Mbps，那不是线路问题
2. 测代理速度，在 PowerShell 里：

```powershell
curl.exe -s -o NUL -x http://127.0.0.1:10809 -w "%{speed_download}" --max-time 15 "https://speed.cloudflare.com/__down?bytes=10000000"
```

数字除以 1048576 就是 MB/s。2 MB/s 以上算正常。

```
- 我做到第 <几> 步（<步骤名字>）

不要一次给多条命令。
```

## 排查顺序（记住这个就不乱）

```
1. 服务端活着吗      → ss -ltnp | grep 443
2. 端口通吗          → Test-NetConnection IP -Port 443
3. 本地程序在吗      → netstat | findstr 10809
4. 参数对吗          → 四处逐字符比对
5. 浏览器读到设置吗  → 完全退出再开
6. 分流对吗          → B站直连 vs Google 走代理
```

**跳步是"越修越乱"的唯一原因。**
