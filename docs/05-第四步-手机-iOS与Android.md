# 第四步：手机（iOS / Android）

> **这一节做什么**：手机上装个 App，把参数填进去。
> **做完你手上会有**：手机能正常上 GitHub / ChatGPT，国内 App 速度不受影响。
>
> 前提：电脑上已经做完 [03-第二步](03-第二步-让机器开始工作.md)，手上有 IP、UUID、public-key、short-id。
> **不需要用数据线连电脑。**

## 共同准备：拿到一条链接

不管哪种手机，先把参数拼成一条链接。

电脑上打开记事本，把下面这段里的四个大写占位符替换掉：

```
vless://你的UUID@你的IP:443?encryption=none&security=reality&sni=www.microsoft.com&fp=chrome&pbk=你的public-key&sid=你的short-id&type=tcp&flow=xtls-rprx-vision#我的线路
```

替换完长这样（示例）：

```
vless://11111111-1111-4111-8111-111111111111@203.0.113.45:443?encryption=none&security=reality&sni=www.microsoft.com&fp=chrome&pbk=AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA&sid=0123456789abcdef&type=tcp&flow=xtls-rprx-vision#我的线路
```

**怎么把这条链接弄到手机上**（任选一种）：

- 微信发给自己 → 手机上复制
- 存到备忘录（iCloud 同步）
- QQ「我的设备」传过去
- 直接发到手机的文件传输助手

> ⚠️ 这条链接等于你的钥匙，**别发到群里、别发朋友圈**。发给自己就行。

# A. iOS（iPhone / iPad）

## A1. 选一个 App

| App | 价格 | 怎么装 | 说明 |
|---|---|---|---|
| **Karing** | 免费 | App Store 直接搜 | **推荐先用这个**，开源、支持我们要的协议 |
| **Shadowrocket**（小火箭） | $2.99 | **需要外区 Apple ID** | 最稳，但要花钱+换区 |
| V2Box | 免费 | App Store 搜 | 能用，界面简陋 |

**中国区 App Store 搜不到 Shadowrocket**，需要美国/香港区账号。
不想折腾账号就用 **Karing**，功能上完全够。

## A2. 导入节点

1. 打开 App，第一次会让你同意条款 → 同意
2. 先在手机上**复制**那条 `vless://` 链接
3. 点右上角或右下角的 **`+`**
4. 选 **从剪贴板导入**（Import from clipboard）

> 如果没找到"从剪贴板"，就选"手动输入"，然后把链接整条粘进去。

导入成功后列表里会出现一条节点，名字是 `我的线路`。

## A3. 检查参数（重要）

点这条节点进详情，确认三项：

- **TLS** 是开的
- **流控 / flow** = `xtls-rprx-vision`
- **REALITY 公钥 / public-key** 有值（不是空的）
- **shortId** 有值

## A4. 连接

1. 回到首页，选中这条节点
2. 打开顶部的开关
3. 系统弹窗「XXX 想要添加 VPN 配置」→ **允许**
4. 输入你的**锁屏密码 / Face ID**

连上后手机顶部会出现 `VPN` 字样。

## A5. 设成规则模式（很重要）

App 里找 **路由 / Routing**：

- Karing：路由 → 选 **规则模式**（Rule）
- Shadowrocket：设置 → **全局路由 → 配置**

**不要选「全局」或「代理」**——那会让抖音、B 站、微信全部绕国外。

## A6. 验证

浏览器打开：

```
https://ipify.org
```

- 显示 VPS 的 IP → ✅ 成功
- 然后打开 B 站 → 应该正常（说明国内直连生效）

## A7. iOS 常见问题

**搜不到 Karing / Shadowrocket**
中国区 App Store 限制。Karing 有时也下架，换成 V2Box 或 FoXray。

**添加 VPN 配置时提示"需要密码"**
就是你的手机锁屏密码，不是 Apple ID 密码。

**连上了但所有 App 都变慢**
模式选成了全局，改成「规则 / 配置」。

**掉了怎么办**
iOS 会偶尔回收 VPN 配置，重新点一下开关即可。

# B. Android

## B1. 选一个 App

| App | 怎么装 | 说明 |
|---|---|---|
| **v2rayNG** | 应用商店搜不到，去 GitHub 搜 `2dust/v2rayNG` → Releases → 下 `.apk` | **推荐**，最常用，Xray 内核 |
| **Karing** | 应用商店 / GitHub | 界面友好，和 iOS 版一样 |
| NekoBox | GitHub | 功能多，稍复杂 |

> 华为/鸿蒙机型可能装不了 Google Play 版，用 GitHub 的 apk 即可。

## B2. 安装（要允许"未知来源"）

1. 下载 `.apk` 文件
2. 点开它，系统会提示「出于安全考虑，禁止安装未知来源应用」
3. 点 **设置** → 打开「允许来自此来源的应用」→ 返回 → 继续安装

> 这是安卓的正常机制，装完可以把这个权限关掉。

## B3. 导入节点

1. 手机上**复制**那条 `vless://` 链接
2. 打开 v2rayNG → 右上角 **`+`**
3. 选 **从剪贴板导入**
4. 列表里出现一条节点

## B4. 检查参数

点节点右侧的 `⋮` → **编辑**，确认：

- **flow** = `xtls-rprx-vision`
- **publicKey** 有值
- **shortId** 有值

## B5. 连接

1. 返回列表，**点一下**节点让它被选中（左边出现小圆点）
2. 点右下角 **▶** 按钮
3. 系统弹窗「连接请求」→ **确定**（允许创建 VPN）

连上后通知栏会有一个钥匙图标。

## B6. 设成"绕过大陆"（很重要）

v2rayNG：右下角 `⋮` → **设置** → **路由设置** → 勾选 **绕过大陆地址**
（或选「绕过局域网及大陆地址」）

**不要用「全局」**。

## B7. 验证

同 iOS：浏览器打开 `https://ipify.org` 看是不是 VPS 的 IP，再打开 B 站看是否正常。

## B8. Android 常见问题

**安裝时提示"解析包出错"**
下载的文件不完整，重新下一遍。或者你的安卓版本太低（需要 8.0 以上）。

**连上了但 App 里显示 0 B**
流量统计本来就不准，只要网页能开就没事。

**后台被杀掉**
安卓的省电策略会杀掉 VPN 应用。去「设置 → 电池 → 应用启动管理」把它设成**允许后台活动**。

**微信/支付宝提示网络异常**
模式选错了（成了全局），改成「绕过大陆」。

# 两边都要注意的三件事

**① 不要用「全局」模式**

全局 = 所有流量绕国外：刷抖音卡、看 B 站慢、微信图片转圈、还费流量。
规则模式只让墙外域名走代理，国内和不开代理时一模一样。

**② 耗电会略增**

VPN 常驻会多一点电，正常现象。不用时在 App 里断开即可。

**③ 一条节点可以多设备共用**

手机和电脑用同一个 UUID 没问题，不需要额外配置。
如果想分开管理（单独停用某台），要在服务端加新 UUID，见 [进阶/04-移动端技术细节](进阶/04-移动端技术细节.md)。
