# 服务端：从买机器到 443 开始监听

## 1. 选机器

| 项 | 选择 | 原因 |
|---|---|---|
| 产品 | **AWS Lightsail**（不要 EC2） | 流量打包、按月计费、界面简单 |
| 套餐 | **$5/月**：1GB 内存 / 2vCPU / 40GB SSD / **2TB 流量** | 个人用绰绰有余 |
| 区域 | **东京 ap-northeast-1**，其次新加坡 | 到 Google/GitHub/ChatGPT 都正常；香港不要选 |
| 系统 | **Ubuntu 24.04 LTS** | 教程与包最全 |
| 网络 | **Dual-stack**（要 IPv4） | 只有 IPv4 就够，但别选 IPv6-only |

其他云（Vultr / DigitalOcean / Hetzner）同理，任意 $5 档机器都可以，脚本通用。

> **注意 AWS 全球区 ≠ AWS 中国区**：个人只能用 `aws.amazon.com`；
> `amazonaws.cn` 需要企业资质与备案，出口等于国内，没有意义。

创建实例时：

- Instance name 随你（如 `tokyo-443`）
- **Automatic snapshots 不要勾**（额外收费）

---

## 2. 开 443 端口（最容易漏的一步）

实例详情页 → **Networking** 标签 → **IPv4 Firewall** → **Add rule**：

```
Application : Custom
Protocol    : TCP
Port        : 443
Source IP   : Anywhere (0.0.0.0/0)
```

> 不要限制成你自己的 IP —— 换网络就连不上了。

最终应该看到两条：`SSH TCP 22`（默认，别删）和 `Custom TCP 443`。

---

## 3. 登录服务器

**下载密钥**：右上头像 → **Account → SSH keys** → 下载 default key（`.pem`）。

**Windows**（Git Bash / PowerShell 均可）：

```bash
icacls "C:\path\key.pem" /inheritance:r /grant:r "%USERNAME%:R"
ssh -i "C:\path\key.pem" ubuntu@<你的IP>
```

权限不修会报 `UNPROTECTED PRIVATE KEY FILE`。

**macOS / Linux**：

```bash
chmod 600 key.pem
ssh -i key.pem ubuntu@<你的IP>
```

## 4. 一键部署（推荐）

把 `scripts/reality-install.sh` 传上去跑：

```bash
scp -i key.pem scripts/reality-install.sh ubuntu@<IP>:/tmp/
ssh -i key.pem ubuntu@<IP> "sudo bash /tmp/reality-install.sh"
```

脚本会：装 Xray → 生成密钥/UUID/shortId → 写配置 → 起服务 → 开 BBR →
**在最后打印客户端要用的全部参数**。

想换伪装站：

```bash
sudo SNI=www.apple.com bash /tmp/reality-install.sh
```

伪装站的三个条件：**支持 TLS 1.3**、**支持 HTTP/2**、**你的 VPS 能连上**。
`www.microsoft.com` / `www.apple.com` / `www.cloudflare.com` 都可用。

## 5. 手工步骤（等价于脚本，想理解每一步就看这里）

```bash
# ① 依赖
sudo apt update && sudo apt install -y curl openssl unzip

# ② 装 Xray（官方脚本）
bash -c "$(curl -fsSL https://github.com/XTLS/Xray-install/raw/main/install-release.sh)" @ install
xray version | head -1 || true      # ← 注意 || true，见排障文档

# ③ 生成三个随机值
xray x25519            # 记下 PrivateKey 和 Password (PublicKey)
xray uuid              # 记下 UUID
openssl rand -hex 8    # 记下 shortId

# ④ 写配置
sudo tee /usr/local/etc/xray/config.json >/dev/null <<EOF
{
  "log": { "loglevel": "warning" },
  "inbounds": [{
    "listen": "0.0.0.0", "port": 443, "protocol": "vless",
    "settings": {
      "clients": [{ "id": "<UUID>", "flow": "xtls-rprx-vision" }],
      "decryption": "none"
    },
    "streamSettings": {
      "network": "tcp", "security": "reality",
      "realitySettings": {
        "dest": "www.microsoft.com:443",
        "serverNames": ["www.microsoft.com"],
        "privateKey": "<PRIVATE_KEY>",
        "shortIds": ["<SHORT_ID>"]
      }
    },
    "sniffing": { "enabled": true, "destOverride": ["http", "tls", "quic"] }
  }],
  "outbounds": [
    { "protocol": "freedom" },
    { "protocol": "blackhole" }
  ]
}
EOF

# ⑤ 启动
sudo systemctl enable --now xray
sudo systemctl status xray --no-pager

# ⑥ 系统防火墙（云安全组之外的第二层）
sudo ufw allow 443/tcp || true

# ⑦ BBR（提升吞吐，可选）
echo "net.core.default_qdisc=fq" | sudo tee -a /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" | sudo tee -a /etc/sysctl.conf
sudo sysctl -p
```

## 6. 验收

**① 端口在听**

```bash
sudo ss -ltnp | grep 443
```

**② 配置不是空的**

```bash
sudo stat -c '%s bytes' /usr/local/etc/xray/config.json
# 必须是几百字节以上；如果是 3 bytes（内容是 {}），说明写入那一步没执行，见排障
```

**③ 从你自己的机器测 TLS**

```bash
openssl s_client -connect <IP>:443 -servername www.microsoft.com </dev/null 2>/dev/null | head -5
```

应当看到 `CONNECTED` 与微软的证书链——这一步只证明"443 通了且握手像正常 HTTPS"，
不代表客户端配置正确。

**④ 真正的功能验证**要用客户端，见 [03-客户端-Windows.md](03-Windows技术配置.md)。

---

## 7. 服务端运维

```bash
sudo systemctl restart xray        # 改完配置重启
sudo journalctl -u xray -n 50 --no-pager   # 看日志
xray version                       # 当前版本
```

- **改配置前先备份**：`sudo cp config.json config.json.bak`
- **文件权限**：`config.json` 应为 `root:xray 640`，含私钥，不要 chmod 644
- **升级**：重跑官方安装脚本即可，升级后建议重新执行一次 `systemctl restart xray`
