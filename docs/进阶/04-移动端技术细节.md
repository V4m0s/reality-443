# 移动端：iOS / Android

手机上不需要任何命令行，一条链接（或二维码）就能导入。

---

## 1. 先拿到节点链接

服务端脚本会打印参数。把它们拼成一条 URI：

```
vless://<UUID>@<IP>:443?encryption=none&security=reality&sni=www.microsoft.com&fp=chrome&pbk=<PUBLIC_KEY>&sid=<SHORT_ID>&type=tcp&flow=xtls-rprx-vision#东京-自建
```

> 这条链接等于你的钥匙，**不要发到群里或截图公开**。

把链接生成二维码（电脑上任意在线工具或 Python）：

```python
import qrcode
qrcode.make("vless://...").save("node-qr.png")
```

## 2. iOS

| App | 价格 | 说明 |
|---|---|---|
| **Shadowrocket** | $2.99 | 最稳，REALITY 支持完整 |
| **Karing** | 免费 | 开源，支持 REALITY |
| **V2Box / Streisand** | 免费 | 可用，界面简陋些 |

> App Store 中国区可能搜不到，需要其他区账号。

**步骤**：

1. 打开 App → 右上角 `+` 或「扫描二维码」→ 扫上面那张图
2. 识别为 `VLESS`，检查三项：`TLS` 开、`流控 = xtls-rprx-vision`、`REALITY 公钥 / shortId` 已填
3. 回到首页 → 选中节点 → 打开开关
4. 系统弹出「添加 VPN 配置」→ 允许 → 输入锁屏密码

**关键设置**：设置 → **全局路由 → 配置**（不要选「代理」或「直连」）。
「配置」= 按规则分流，国内直连。

## 3. Android

| App | 来源 | 说明 |
|---|---|---|
| **v2rayNG** | GitHub Releases 下 apk | 最常用，Xray 内核 |
| **Karing** | Play / GitHub | 界面现代，跨平台 |
| **NekoBox** | GitHub | 功能多，稍复杂 |

**步骤（v2rayNG）**：

1. 右下角 `+` → **从二维码导入** → 扫码
2. 点节点进入详情，确认 `flow = xtls-rprx-vision`、`publicKey`、`shortId` 三项非空
3. 返回列表 → 点节点 → 底部 ▶ 连接
4. 首次会请求 VPN 权限 → 允许

**关键设置**：设置 → **路由设置 → 绕过大陆地址**（或「绕过局域网及大陆地址」）。

---

## 4. 为什么不要用「全局」

全局模式 = 所有流量都绕东京：

- 刷抖音、看 B 站、微信收发图 → 全部多绕 2000 公里
- 耗电、耗流量（套餐 2TB 会用得很快）
- 国内 App 可能因出口 IP 突变触发风控（登录异常、验证码）

规则模式只让墙外域名走代理，国内流量与不开代理时完全一致。

---

## 5. 验收

连接后：

1. 浏览器打开 `https://ipify.org` → 应显示你的 VPS IP
2. 打开 B 站 → 应正常加载（说明国内分流生效）
3. 打开 GitHub → 应正常（说明代理生效）

## 6. 多设备

同一个 UUID 可以被多台设备同时使用，不需要额外配置。

如果想**分开管理**（独立限速、独立停用），在服务端 `clients` 数组里加多项即可：

```json
"clients": [
  { "id": "<UUID-1>", "flow": "xtls-rprx-vision", "email": "phone" },
  { "id": "<UUID-2>", "flow": "xtls-rprx-vision", "email": "laptop" }
]
```

改完 `sudo systemctl restart xray`。生成新 UUID：`xray uuid`。
