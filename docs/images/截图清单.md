## 打码规则

| 内容 | 处理 |
|---|---|
| UUID / public-key / short-id | 完全涂掉 |
| 公网 IP | 后两位涂掉，如 `57.180.41.**` |
| 邮箱、姓名、地址、卡号 | 涂掉 |
| 桌面其他窗口 | 截图前最小化 |

打码用 Windows 自带「画图」：粘贴 → 白色笔刷涂 → 另存 PNG。
