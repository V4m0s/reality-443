# 自己搭一条稳定的网络线路（给完全不懂技术的人）

> 花 30 分钟、每月 5 美元，拥有一条**只属于你自己**的线路。
> 不用买机场、不用懂代码、不用域名。

---

## 第一步：先找到你的路线

**服务器那两步（02、03）所有系统都一样**，只有"让设备用上它"这一步分系统。

| 你的设备 | 按这个顺序读 | 预计时间 |
|---|---|---|
| **Windows 电脑** | 00 → 02 → 03 → **04a** → 06 | 30 分钟 |
| **Mac 电脑** | 00 → 02 → 03 → **04b** → 06 | 30 分钟 |
| **iPhone / iPad** | 00 → 02 → 03 → **05A** | 25 分钟 |
| **安卓手机** | 00 → 02 → 03 → **05B** | 25 分钟 |
| 电脑 + 手机都要用 | 电脑那篇 + **05A** 或 **05B** | 35 分钟 |

> **05A / 05B 是什么**：同一篇文档 [05-第四步-手机](docs/05-第四步-手机-iOS与Android.md) 里的两节——
> **A 节 = iOS**（iPhone / iPad），**B 节 = Android**。从 A 节或 B 节开始看就行，不用读另一节。

> **在学校里用？** 做完电脑那一步之后，还要看 [09-校园网特殊配置](docs/09-校园网特殊配置.md)——
> 校园网会按域名拦抖音/4399，默认分流会把它们判成直连，需要额外加一条规则。
>
> **哪天突然全断了？** 大概率是你的服务器 IP 被学校拉黑了，看
> [10-学校封了服务器IP怎么办](docs/10-学校封了服务器IP怎么办.md)——不用换服务器，加一层 Cloudflare 就行。

> **只有手机、没有电脑？** 服务器那两步（02、03）需要电脑，因为要开网页和命令行。
> 借同学的电脑做 10 分钟就够了，做完把参数记下来，手机上照 05 配。

## 三种看法，挑一个

### 🅰 我懒得看，也看不懂 —— 交给 AI

把这个仓库的地址复制给你手边的任意一个 AI 助手（豆包工作版、DeepSeek Harness、Hermes、Codex、Claude、ChatGPT 都行），然后发这句话：

```
这是我的仓库：https://github.com/V4m0s/reality-443

我的设备是 <Windows / Mac / iPhone / 安卓>。
我看不懂里面的技术内容，请你一步步带我做完：
1. 先确认我要读哪几篇（我这个系统该走哪条路线）
2. 每一步只给我一个操作，等我回复"好了"再给下一步
3. 每次我说"卡住了"，你就问我看到了什么报错，然后给我解决办法
4. 不要一次给我一大堆命令，我复制不过来
```

具体怎么用见 [docs/07-看不懂就交给Agent.md](docs/07-看不懂就交给Agent.md)。

### 🅱 我想自己动手 —— 照着上面那张表走

每篇都写清楚了「你要点什么、会看到什么、出错了怎么办」，
每节末尾有 ✅ 检查点，打勾了再往下走。

### 🅲 我想搞明白它为什么管用

先读 [docs/01-它是怎么回事.md](docs/01-它是怎么回事.md)。里面有快递、信封、门牌号的比喻，
读完你就能跟别人解释清楚这件事，而不只是"照着做了"。

## 要花多少钱、难不难

| 问题 | 答案 |
|---|---|
| 多少钱 | **每月 5 美元**（约 36 元），含 2TB 流量，个人用绰绰有余 |
| 要信用卡吗 | 要。没有可以找家人借，或者用支持银联的虚拟卡 |
| 要多懂电脑 | 会双击、会复制粘贴、会打字，就够了 |
| 要买域名吗 | **一般不要**。只有"学校封了你的 IP"才需要，免费域名也行（见 10） |
| 要备案吗 | **不要** |
| 要会写代码吗 | **不要**。所有命令我都写好了，你复制粘贴 |
| 会很难吗 | 第一次大约 30 分钟。卡住就看 [06](docs/06-出问题了怎么办.md)，或者直接问 AI |

## 先说清楚三件事

**1. 这不是"机场"，它只属于你。**

机场是一台机器几百人共用，任何一个人乱来，所有人都受影响。这条线路只有你和你的设备，
你随时可以换 IP、改配置、关掉它。

**2. 它会花钱，而且是持续的。**

每月 5 美元，从信用卡扣。不想用了要去 AWS 控制台**把机器删掉**，不是关掉——关机也收费。

**3. 它需要你懂一点点，但不多。**

第一次会遇到几个"咦这是什么"的地方，文档里都写了。实在不行，把仓库丢给 AI（🅰 那条路）。
